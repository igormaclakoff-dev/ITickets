# ITickets

Плагин тикетов для Paper/Purpur 1.21.7 с GUI, шаблонами ответов, внутренними заметками и расширенным меню персонала.

## Возможности

- **Система тикетов** — создание, ответ, закрытие, переоткрытие, оценка
- **Статус "В работе"** — физический статус `IN_PROGRESS`, автоматический перевод при взятии
- **Шаблоны ответов** — ~29 готовых шаблонов с группировкой, пагинацией и поддержкой плейсхолдеров
- **Внутренние заметки** — скрытые заметки персонала, видны только сотрудникам
- **Управление тикетом** — смена важности и категории прямо из меню просмотра
- **Расширенное меню персонала** — вкладки "Открытые", "В работе", "Назначены мне", профиль со статистикой
- **Автозакрытие и напоминания** — настраиваются в `config.yml`
- **Экспорт** — `/iticket export [csv|txt]` в `plugins/ITickets/exports/`
- **Единый стиль чата** — компактные уведомления с префиксом `[IT]`
- **Современный GUI** — обновлённый дизайн с цветовыми акцентами

## Команды

- `/iticket` — открыть меню тикетов
- `/iticket create` — создать тикет
- `/iticket view <id>` — открыть тикет
- `/iticket comment <id> <текст>` — ответить
- `/iticket staff` — меню персонала
- `/iticket assign <id> <ник>` — назначить ответственного
- `/iticket export [csv|txt]` — экспорт базы тикетов
- `/iticket reset confirm` — очистка базы тикетов

## Установка

1. Скачать `ITickets-1.0.0.jar`
2. Поместить в папку `plugins/`
3. Запустить сервер для генерации конфигов
4. Настроить `config.yml`, `gui.yml`, `messages.yml`, `templates.yml` под себя

## Конфиги

- `config.yml` — основные настройки, автозакрытие, напоминания
- `gui.yml` — настройка меню
- `messages.yml` — тексты сообщений
- `permissions.yml` — права доступа
- `templates.yml` — шаблоны ответов персонала
- `categories.yml` — категории тикетов

## Требования

- Paper/Spigot/Purpur 1.21.x
- Java 21
